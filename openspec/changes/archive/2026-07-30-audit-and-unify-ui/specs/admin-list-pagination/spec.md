## ADDED Requirements

### Requirement: 后台分页不受首页轻量分页影响

后台管理列表 SHALL 继续使用数字页码分页，以支持管理员访问完整运营数据；首页 topic feed 的轻量分页模式不得改变后台分页体验。

#### Scenario: 后台保留数字分页

- **WHEN** 管理员访问支持分页的后台管理列表
- **THEN** 分页控件允许访问上一页、下一页和附近页码
- **AND** 不得退化为只显示上一页/下一页。

#### Scenario: 后台翻页保留筛选条件

- **WHEN** 管理员在后台列表中带搜索或筛选条件翻页
- **THEN** 新页面 URL 保留当前搜索或筛选参数
- **AND** 后台接口按这些条件返回对应页数据。
